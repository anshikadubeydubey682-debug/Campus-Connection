# Campus Connection

A full-stack campus management and student collaboration platform.

## About

Campus Connection is designed to help students connect, collaborate,
and access useful campus-related services through a single platform.

## Technologies Used

- Java
- Spring Boot
- HTML
- CSS
- JavaScript
- MySQL

## Features

- Student registration and login
- Student collaboration
- Campus management
- User management

## Project Structure

- `src/` - Source code
- `pom.xml` - Maven configuration
- `target/` - Build files

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA or Eclipse.
3. Configure the database.
4. Run the Spring Boot application.
